# Se servir d’**Obsidian** en général
## Fonctions natives

### Utiliser les syntaxes _MarkDown_ spécifiques
#### Référencer du texte d’autres notes
Pour citer une autre note en entier on peut utiliser :
```markdown
![[autrenote]]
```
Et on peut également limiter à une section : 
```markdown
![[note#section]]
```
Si on souhaite se débarrasser du titre de la section :
```markdown
![[note^ section]]
```
