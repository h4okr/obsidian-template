# obsidian-template
Patron pour une *vault* [Obsidian](https://obsidian.md/) orientée prise de notes professionnelles.
[English version of this file](./README.md).
## Plugins
### Plugins inclus dans cette *vault*
* [Admonition](https://github.com/javalent/admonitions) : écriture facilité d’encarts attirant l’attention,
* [Advanced tables](https://github.com/tgrosinger/advanced-tables-obsidian) : manipulation des tableaux,
* [Calendar](https://github.com/liamcain/obsidian-calendar-plugin) : un calendrier intégré à l’interface,
* [Datetime Language Changer](https://github.com/ZetabS/datetime-language-changer) : pour formater les noms avec *templater* par des dates écrites en français
* [Iconize](https://github.com/FlorianWoelki/obsidian-iconize) : permet d’ajouter des icônes aux dossiers et fichiers,
* [Periodic Notes](https://github.com/liamcain/obsidian-periodic-notes) : étend la notion de note quotidienne aux semaines, mois, …
* [Templater](https://github.com/SilentVoid13/Templater) : permet de créer des patrons pour les notes.
### Autres plugins recommandés
Je recommande vivement les plugins suivants :
* Dataview : pour visualiser des statistiques internes,
* Style Settings : pour personnaliser le style d’**Obsidian**,
* Meta Bind : pour ajouter des champs de saisie dans les notes,
* Metadata Menu : pour rendre *frontmatter* plus interactif,
* Underline : ajout de raccourci pour souligner et centrer du texte,
* Various Complements : proposition d’auto-complément comme sur un environnement de développement,
* Tasks : pour faire du suivi de tâche très précis.
## Comment commencer ?
1. Installer [Obsidian](https://obsidian.md/),
2. Télécharger ce projet,
3. Utiliser le dossier téléchargé comme *vault*,
4. Lire le [[mode d’emploi]].
